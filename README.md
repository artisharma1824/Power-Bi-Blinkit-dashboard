# Blinkit Sales Performance Dashboard | Power BI

An interactive Power BI dashboard created to analyze Blinkit's retail sales, outlet performance, and customer satisfaction metrics.

## 📊 Dashboard Preview
![Blinkit Dashboard Preview](./2026-10-22%20\(1\).png)

## 🔑 Key Features & Analysis
- **KPI Metrics:** Total Sales, Average Sales, Average Customer Rating, and Item Count.
- **Data Transformation:** Performed data cleaning, null handling, and type casting using Power Query.
- **DAX Calculations:** Built custom DAX measures for aggregated sales metrics and outlet statistics.
- **Interactive Visualizations:** Line charts, donut charts, funnel charts, and matrix breakdown by outlet size, location type, and item category.

## 📁 Repository Contents
- `Blinkit Dashboard.pbix`: Power BI report file containing data models and visuals.
- `BlinkIT Grocery Data.xlsx`: Source dataset used for analysis.
- `2026-10-22 (1).png`: Dashboard preview image.

## 🛠️ Tools & Tech Stack
- **Tool:** Power BI Desktop
- **Data Modeling:** Power Query, DAX
- **Data Source:** Excel Dataset
